# FreeDict eng-spa dictionary

`freedict-eng-spa.tei` is the English-Spanish dictionary from the
[FreeDict](https://freedict.org) project (edition 2025.11.23, 64,258 headwords),
built by [WikDict](http://www.wikdict.com/) from [Wiktionary](https://www.wiktionary.org/)
data via [DBnary](http://kaiko.getalp.org/about-dbnary/).

License: [Creative Commons Attribution-ShareAlike 3.0 Unported](https://creativecommons.org/licenses/by-sa/3.0/legalcode).

It is used only for local, traditional (non-AI) dictionary lookups — no
translation model or external API is involved. See `app/workers/seed_dictionary.py`
for how it's parsed and loaded.
